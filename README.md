# 4friends Client

Launcher und Client-Mod für die 4friends-Gruppe: Minecraft mit eigenem Menü, Cosmetics, Emotes, gemeinsamer Musik und mehr.

## Installieren

1. Unter [Releases](https://github.com/CookieakaKrizzpy/4FriendsClient/releases/latest) die Datei `4friends-Client-Setup-….exe` herunterladen.
2. Starten. Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“ – auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken.
3. Im Launcher oben rechts mit dem Microsoft-Konto anmelden.

Neue Versionen lädt der Launcher danach selbst herunter – oben in der Titelleiste erscheint dann „Version … – neu starten“.

Der Quellcode liegt nicht in diesem Repository; hier gibt es nur die fertigen Versionen.
